# ユーザーにコマンド実行を依頼するときはクリップボードに入れる

auto mode でブロックされたコマンドや対話ログインが必要なコマンドなど、ユーザーに実行を依頼する場合は、
本文にコマンドを示すだけでなく、そのコマンドを Windows のクリップボードにも入れておくこと。
ユーザーが手でコピーする手間を省くため。

```bash
printf '%s' "$(cat <<'EOF'
! <実行してほしいコマンド>
EOF
)" | win32yank.exe -i
```

- `win32yank.exe` を使う（`clip.exe` は日本語が文字化けする）
- 末尾の改行は入れない（貼り付けた瞬間に実行されるのを防ぐ）。上の `$(...)` で除去される
- 先頭に `! ` を付けて入れる（Claude Code のプロンプトにそのまま貼って実行できるように）
- 複数コマンドを依頼する場合は、1回で貼って実行できる形（`&&` 連結など）にまとめて入れる
- 返答では「クリップボードに入れた」と一言添える
