# TODO を案件ごとにまとめて見出しを出す（設計）

## 目的

やる・待ちに色々な案件の行が入り乱れていて見づらい。案件ごとにまとめ、`── パイロット (4) ──` の見出しで区切って見せる。
ただし AI（/todo）の判断は増やさない。案件の判定は決まった表で機械的に行う。

## ゴール / 非ゴール / アンチゴール

- ゴール: やる・待ちが案件ごとに固まり、各かたまりの上に見出し（案件名と件数）が出る。見出しは常に表示（開閉しない）
- 非ゴール: 折りたたみ、行の頭の色ラベル、完了欄のまとめ
- アンチゴール: LLM に案件を判定させる・案件名を todo.md の行に書く（AI の判断と形式を増やす）

## 方式の検討

| 案 | 内容 | 判断 |
|---|---|---|
| A | 並びはそのまま、行の頭に案件ラベル | 見送り。混ざったままで色で見分けるだけ |
| B | 表で案件を決め、書き出し時に案件ごとに並べ替え、見出しを表示だけで出す | **採用** |
| C | B を折りたたむ | 見送り。ユーザーが「開閉は不要、常に開いていて欲しい」 |
| (AI 判定) | /todo に案件名を付けさせる | 却下。AI の判断が増える |

今の todo.md に表を当てた試作で、key だけでは分け間違う行（epc#1176・eae#59 は AIeBASE 共通）があると分かったため、表は上から順に見て「key を丸ごと書けば行単位で決め打ちできる」形にする。

## 設計

### 案件の表 `~/memo/todo-groups.json`

置き場所は todo.md と同じディレクトリ（`TODO_MD_PATH` の dirname）。顧客名を GitHub の dotfiles に置かないため。

```json
{"groups": [
  {"name": "パイロット", "keys": ["gb:WEB#", "gb:java-source#"], "words": ["パイロット"]},
  {"name": "阪急", "keys": ["gb:ebase-web#", "ebpm:"], "words": ["阪急", "キッチンエール"]},
  {"name": "AIeBASE 共通", "keys": ["eae#", "epc#1176"], "words": ["APIキー", "JSESSIONID"]},
  {"name": "シフトオン", "keys": ["epc#"], "words": ["シフトオン", "車両", "越智さん", "mensapo"]},
  {"name": "プラス", "keys": [], "words": ["プラス"]},
  {"name": "研修・会議", "keys": ["gb:tamaki-ai-training#"], "words": ["玉木", "研修", "開発会議", "インターン"]}
]}
```

- 判定: 表を上から見て、最初に当たった案件。当たり = `keys` のどれかに key が一致（`#` か `:` で終わる要素は前方一致、それ以外は完全一致）するか、`words` のどれかが題（key のリンクと next を除いた部分）に含まれる。どれにも当たらなければ `その他`
- 並び: 表の順、`その他` は最後
- 表が無い・読めないときはまとめない（今までどおり）。読めないときは stderr に1行出す（無人実行を止めない）

### 並べ替え（決定的）

- Python: apply.py が todo.md を書き出す直前に、やる・待ちを案件の順で安定ソートする。同じ案件の中の順（AI の order・人の並び）は崩さない。完了は触らない。answers.py は apply.run を通るので同じ
- nvim: ポップアップを閉じてコミットする直前に、同じ規則でファイルを並べ替える（手で足した行も正しい案件の下に入る）。開いている間は並べ替えない（Enter のたびに行が動くと混乱するため）

### 見出し（表示だけ）

- やる・待ちで、タスク行の案件が直前のタスク行と変わるところ（各欄の先頭を含む）の上に、仮想行で `── <案件> (<そのかたまりの件数>) ──` を出す。ファイルには書かない
- 表が無ければ出さない

### /todo の SKILL.md

規則 9（order）に「apply が書き出し時に案件ごとにまとめるので、order は案件の中の順として効く」と1行足す。

## 決めたこと（Claude の判断）

- 表の置き場所（~/memo）と JSON 形式、`#`/`:` 終わりは前方一致・それ以外は完全一致
- 並べ替えを apply.py の書き出し直前と nvim の閉じる直前に置く
- 見出しのハイライト（Title）と書式

## 実装者に任せること

- 見出しの仮想行が窓の先頭行の上に来る場合の扱い
